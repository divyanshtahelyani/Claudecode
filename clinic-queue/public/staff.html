Install as an app

  • Windows / Mac (Chrome or Edge): click ⬇ Install app above, or the install icon at the right end of the address bar.

  • iPhone / iPad (Safari): tap Share → Add to Home Screen.

It then opens from its own icon in its own window, like any other app.
